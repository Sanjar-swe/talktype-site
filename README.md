# TalkType — клавиатура с диктовкой для Android

**Сайт: https://sanjar-swe.github.io/talktype-site/**
**Запись в бету: https://t.me/talktype_master_bot**

Говорите как умеете — отправляйте как надо.

TalkType — экранная клавиатура для Android со встроенной кнопкой микрофона. Вы переключаетесь
на неё в любом приложении (Telegram, WhatsApp, СМС, браузер), нажимаете микрофон и говорите
своими словами. Речь распознаётся, языковая модель убирает «э-э», повторы и ошибки и переписывает
сообщение вежливым деловым тоном, а готовый текст вставляется прямо в поле ввода.

Сделано для тех, кто говорит по-русски лучше, чем пишет: в первую очередь для трудовых мигрантов
в России. Плохо написанное сообщение работодателю или хозяину квартиры стоит денег и работы —
эту боль продукт и решает.

## Коротко

| | |
|---|---|
| Платформа | Android 10 и новее (iOS нет) |
| Языки интерфейса | русский, узбекский |
| Статус | в разработке, открыт набор в закрытую бету |
| Цена | 2000 слов в месяц бесплатно, дальше — разовые пакеты слов, без подписки |
| Оплата | звёздами Telegram прямо в боте, банковская карта не нужна |

## Чем отличается

- **Не голосовое сообщение.** Голосовое слушают не сразу: начальник за рулём, в рабочем чате
  шумно. Текст читают сразу и отвечают быстрее — но писать его самому долго и с ошибками.
- **Не требует особых разрешений.** Основной канал — обычная клавиатура (IME), а не служба
  специальных возможностей. Плавающая кнопка поверх приложений есть, но она необязательна.
- **Не читает экран и не перехватывает набор.** Вставляется только то, что вы надиктовали,
  нажав кнопку.
- **Голос нигде не хранится.** Запись удаляется с телефона сразу после отправки, на сервере
  обрабатывается только в памяти. Текст сообщений не сохраняется.

## Режимы текста

| Режим | Что делает |
|---|---|
| Вежливо и грамотно (по умолчанию) | чистит речь и переписывает в вежливом деловом тоне |
| Убрать лишнее | убирает «э-э», повторы, самоисправления; ставит пунктуацию |
| Коротко | сжимает до сути |
| Как сказал | только распознавание, без переписывания |
